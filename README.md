# LucidHackType
A simple tool to write code easily everywhere

# How to use
You can close this project while it is not published on [crates.io](https://crates.io).

When clone you can go into the folder with:
```bash
cd LucidHackType
```

When you are in the repository you can test if it works with this command:
```bash
cargo rr -- -f ./src/main.rs
```

Then, go to the file `test.rs` in any IDE and do `ctrl + shift + H` to enable hacker type mode then juste spam you're keyboard and see the beautiful code.
